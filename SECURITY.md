# Security Policy

## Reporting a vulnerability

**Please do not open a public issue, discussion or pull request for a security problem.**

Report it privately through GitHub's private vulnerability reporting:
open the repository's **Security** tab and choose **Report a vulnerability**
(`https://github.com/Al-Ummah-Now/openauth/security/advisories/new`).

Please include:

- what is affected (URL, endpoint, file or version) and the impact;
- steps to reproduce or a proof of concept;
- anything you already know about a fix.

We aim to acknowledge reports within 3 working days and to keep you updated
until the issue is resolved. With your permission we will credit you in the
published advisory.

## Scope

In scope: the code in this repository and the Al Ummah Now services built from it
(`*.alummahnow.net`).

Please test only against accounts you own, do not access or modify other
people's data, and do not run denial-of-service or volume tests.

## Leaked credentials

If you find a credential in this repository or its history, report it the same
way. Do not use it beyond what is needed to show that it exists.

## Supported versions

Only the latest release (the `main` branch) receives security fixes.
